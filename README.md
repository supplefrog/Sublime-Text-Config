# Sublime Text Config

Personal Sublime Text user settings and Package Control package list.

## Restore

Copy the files under `Packages/User/` into your Sublime Text User package directory:

- Windows: `%APPDATA%\Sublime Text\Packages\User`
- macOS: `~/Library/Application Support/Sublime Text/Packages/User`
- Linux: `~/.config/sublime-text/Packages/User`

Install [Package Control](https://packagecontrol.io/installation) first, then restart Sublime Text to install listed packages.
